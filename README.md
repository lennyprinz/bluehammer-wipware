## Requirements

- Windows 10 / Windows 11
- PowerShell 5.1 or newer
- Administrator privileges if required by individual operations

## Installation

Clone the repository:

```bash
git clone https://github.com/lennyprinz/bluehammer-wipware.git
```

Navigate to the project directory:

```powershell
cd bluehammer-wipware
```

## Execution

Run the PowerShell script:

```powershell
.\BlueHammer-Wipware.ps1
```

If script execution is restricted, review your PowerShell execution policy before proceeding.

## Security Notice

Only execute scripts from trusted sources.

Review the source code before running it, especially when administrator privileges are required.
